# results/evidence

> Purpose: Compatibility directory for historical evaluation artifacts.

## Español

Esta carpeta conserva el alias `savh` para los recursos SAVH históricos. Los nuevos resultados por país deben guardarse en `results/ecuador/` o `results/usa/`.

## English

This directory keeps the `savh` compatibility alias for historical SAVH artifacts. New country-specific results should be stored under `results/ecuador/` or `results/usa/`.
