# Datasets YOLO de Ecuador

El entrenamiento descarga Roboflow directamente a `/content/datasets` en Colab para evitar almacenar una segunda copia grande en Git. Si quieres usar un ZIP local, colócalo aquí como `dataset_placas_yolo.zip` y selecciona `DATASET_SOURCE = "local"`. No se publica automáticamente el dataset descargado.
