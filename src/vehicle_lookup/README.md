# src/vehicle_lookup

> Purpose: Vehicle information lookup adapters for supported countries.

## Español

Ecuador usa el SRI. EE. UU. usa J.D. Power (`api/providers/usa_jdpower.py`), activado con `vehicle_lookup.enabled` en `config/countries/usa.yaml` tras confirmarse el acceso autorizado.

## English

Ecuador uses SRI. The U.S. uses J.D. Power (`api/providers/usa_jdpower.py`), switched on with `vehicle_lookup.enabled` in `config/countries/usa.yaml` after authorized access was confirmed.
