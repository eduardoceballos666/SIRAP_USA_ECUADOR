# config/countries

> Purpose: Country-specific rules and provider settings.

## Español

`ecuador.yaml` contains the current operational settings. `usa.yaml` is preparatory and keeps U.S. vehicle lookup disabled until the integration is authorized and implemented.

## English

`ecuador.yaml` contiene los parámetros operativos actuales. `usa.yaml` es preparatorio y mantiene desactivada la consulta vehicular de EE. UU. hasta autorizar e implementar la integración.
